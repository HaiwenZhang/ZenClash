# ZenClash Service 安全政策

Modified for the ZenClash fork on 2026-10-04; see NOTICE.md. GPL-3.0-only.

这是从 clash-verge-service-ipc 2.7.5 导入并适配标识的特权服务。支持 Windows、macOS 和 Linux 的源码分支，不表示三个平台已完成本 Fork 的实机安全验证。

当前仅维护 ZenClash 集成使用的版本；不沿用上游未填写模板中的虚构版本支持表，也不承诺未设立的私密报告渠道或修复时限。报告问题时应说明 ZenClash 提交、目标平台、服务版本和复现步骤，避免公开订阅链接、控制器密钥和所有者令牌。

请通过 ZenClash 项目实际提供的安全报告渠道联系维护者；若未提供私密渠道，先联系维护者建立渠道，再发送敏感漏洞细节。能够独立在上游复现的问题，也可按 [上游安全政策](https://github.com/clash-verge-rev/clash-verge-service-ipc/security/policy) 报告。Fork 特有的标识、安装路径或接入问题由 ZenClash 维护者处理。
