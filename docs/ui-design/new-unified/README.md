## 本轮调整

- 所有窗口标题栏统一采用本目录 zenclash-logo.png 的青绿色折带 Z 标志，来源于上一轮 zenclash-logo-v2.png。
- 主导航统一为总览、代理、订阅、连接、规则，设置固定底部。取消“工具”导航名称；规则下保留规则、日志、网络诊断二级入口。
- 代理宽屏保留左侧六个代理组；右侧三列节点卡片，不再使用节点表格和独立切换按钮。窄窗通过代理组选择器保留分组访问，卡片双列排列。
- 点击卡片直接请求切换当前手动代理组的节点。成功后显示勾选与当前状态；等待期间显示处理中，失败保留原节点并说明原因。自动组与负载均衡组按内核能力展示，不伪装为手动组。
- 卡片提供节点名、协议、UDP 与延迟；超时只代表测试结果，不永久禁用节点。详情与重测通过独立菜单访问，不能误触发切换。
- 键盘进入卡片区域后使用方向键移动焦点，Enter/Space 切换；焦点和当前节点分别表达。响应式变化保留当前组、节点、搜索、滚动及弹层状态。

## 响应式约定

桌面优先，延续原设计最小窗口约 720×560 的约定。宽屏显示文字侧栏和辅助面板；中窄窗口收为图标栏，详情按需打开；设置为单列限宽表单。卡片按内容可用宽度从三列收为两列，放大字体后空间不足时可继续降为一列。低高度仅滚动正文，主要操作与导航保持可达。高级网络展开状态属于用户操作，图中展示不同状态不表示缩窗自动折叠。

## 核验范围

8 张最终 PNG 已逐张视觉检查：统一 Z 标志、规则导航、当前选中态、中文关键标签、节点卡片、宽窄重排。总览窄窗导航文字和网络折叠箭头已做定向校订。所有图片为 1536×1024 的设计概念板，共含 17 个窗口布局，不是逐像素的原生截图；实际 DPI、键盘、辅助技术与大数据性能需要实现后验证。图片里 Logo 为同一参考生成，正式实现应直接复用单一源资产以保证像素级一致。
