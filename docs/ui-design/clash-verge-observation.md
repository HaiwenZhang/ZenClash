# Clash Verge 界面观察与 ZenClash 取舍

2026-10-07。经用户明确授权，只读查看本机 Clash Verge 窗口。可见版本为 v2.5.7；此记录仅描述本机所见，不推断其他版本。未改变代理、订阅、网络或设置选项；完成后关闭查看用的界面设置弹层，停留在设置页。原始截图及私人订阅、连接和日志数据不写入仓库，设计图使用虚构示例。

## 实际看到的页面

侧栏有：首页、代理、订阅、连接、规则、日志、测试、设置。本轮实际查看代理、订阅、连接、规则、日志、设置，以及设置中的界面设置弹层；首页与测试仅确认导航存在，没有逐项检查内部功能。

| 页面 | 实际观察 | ZenClash 设计决定 |
| --- | --- | --- |
| 代理 | 顶部模式选择，分组展开，节点网格，当前节点、测速、排序、过滤与节点数量 | 保留模式与分组；搜索和测速使用有文字的入口；宽屏列表与详情，窄窗单列 |
| 订阅 | URL 导入、新建、订阅卡片、额度和到期日；全局扩展覆写配置与脚本并列展示 | 当前订阅显式标注；编辑选择与启用区分；高级覆写收起；不复制用户的真实订阅名称 |
| 连接 | 活跃/已关闭、过滤、列控制、关闭全部；多列展示流量、速率、链路、规则、进程、地址 | 首屏保留目标、进程、策略和流量；完整链路进入详情；批量关闭放更多菜单并明确范围 |
| 规则 | 过滤输入、顺序编号、匹配内容、类型和策略，紧凑列表 | 保留顺序；宽屏对比式表格，窄窗两行记录；不增加无来源的命中图表 |
| 日志 | 级别选择、过滤、暂停、排序、清除；时间/级别与正文分两行 | 保留组合筛选；区分暂停接收与自动跟随；详情可复制；存储保留策略归数据设置 |
| 设置 | 系统设置、Clash 设置、Verge 基础设置、Verge 高级设置分组；宽窗两列 | 参考分组而不照搬密集长页；改为常规、网络、数据、关于，默认仅打开一个分类 |

## 设置页看到的选项

- 系统：虚拟网卡模式、系统代理、开机自启、静默启动。
- Clash：局域网连接、DNS 覆写、IPv6、统一延迟、日志等级、端口、外部控制、网页界面、内核、UWP 工具、GeoData 更新、流量隧道管理。
- Verge 基础：语言、主题、托盘点击事件、复制环境变量类型、启动页面、启动脚本、主题设置、界面设置、杂项设置、热键设置。
- Verge 高级：备份、当前配置、配置/内核/日志目录、检查更新、开发者工具、轻量模式、退出、导出诊断信息、版本。
- 界面设置弹层：系统标题栏、流量图、内核占用、代理组图标、失焦暂停渲染、通知位置、悬浮跳转及延迟、导航图标、收起导航、托盘代理组模式、托盘菜单与图标定制。

以上是可见入口清单，未执行会变更配置或产生网络操作的动作，也未打开所有高级子窗口。

## 对精简方案的影响

Clash Verge 并非选项少，而是分组清楚且不少功能进入二级弹层。ZenClash 应借鉴任务分组与渐进展示，不继续增加“界面偏好”的开关数量。

1. 常规仅四项已存在偏好：主题、语言、开机启动、托盘显示速率。没有为了对齐 Verge 的静默启动而新增业务设置。
2. 网络保留系统代理、TUN、局域网连接；DNS、IPv6、端口、覆写、资源、内核等进入高级配置。
3. 数据承接历史、日志保留、备份；关于承接版本、更新和许可。
4. 规则和日志仍有完整独立页面，通过工具页固定标签进入，不因为主导航精简而删除功能。用户本次要求的五个页面均提供独立宽窄设计图。
5. 不引入悬浮自动导航、图标替换、通知位置等额外开关；优先提供稳定默认行为。

观察到代理网格会随可用宽度改变列数，但未系统测试 Clash Verge 的最小窗口、DPI 或全部断点；不能将本轮观察作为其自适应质量的完整验收。
