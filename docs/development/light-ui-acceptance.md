# 浅色界面对照验收

2026-10-06。以 `docs/ui-design` 的最终浅色设计稿为基准，完成七个主页面的布局与交互对照。设置页面不在本次改版范围内。

| 页面 | 对照内容 | 操作验收 |
| --- | --- | --- |
| 总览 | 运行状态、速率卡片、五分钟趋势、当前订阅、水波百分比、活动、节点、最近连接 | 当前订阅与实际配置一致；运行时间来自真实内核进程 |
| 代理组 | 分组、节点表、当前节点、延迟历史、自动选择详情 | 搜索、排序菜单、空结果恢复、真实节点切换及控制器读回 |
| 订阅 | 配置摘要、双列仓库、选中与已应用状态、流量详情、当前配置 | 切换后真实配置验收；新增、请求设置、更新间隔菜单的键盘与取消行为 |
| 连接 | 四项摘要、分布图、表格、选中行、连接详情 | 传输类型过滤、暂停与恢复、排序、详情、关闭操作的测试覆盖 |
| 规则 | 摘要、分布、表格、规则详情与流程 | 搜索、分页、选中、无结果恢复、加载时保留现有内容 |
| 网络诊断 | 摘要、主检查、目标、网络能力、公网 IP、扩展详情 | 真实探测、展开与收起、失败结果保留、目标编辑取消 |
| 日志 | 标题与工具栏、状态栏、过滤、表格、详情、级别分布、落盘 | 真实日志选中、暂停、清空确认取消、原生导出取消 |

共同修正包括页面标题字号、侧栏图标和文字、卡片间距、对齐、表格分隔线、选中与禁用状态，以及浅色页面渐变。水波组件随真实额度变化，并支持减少动态效果。

最后一轮真实窗口验收发现并修复了订阅请求设置表单的焦点和取消问题：打开后聚焦名称输入框；Escape 取消编辑并恢复页面焦点；未提交内容不写入配置。通过真实窗口再次确认，取消后当前订阅仍为 ikuu。
