# 自动运行维护验证

## 行为与状态所有者

- `CoreSession` 串行管理启动、暂停、重启与退出。`NetworkSuspended` 与手动 `Stopped` 分开，前者允许联网恢复，后者只允许显式重启。退出开始时立即设置不可恢复标记。
- `TrafficCaptureSession` 释放自身持有的系统代理并保留用户意图；内核停止会释放 TUN，恢复启动继续使用原来的有效配置。接管恢复失败会显示错误；不会静默授权或改写导入文件。
- `app/automatic.rs` 在后台检查非隧道接口、当前源配置及启用的覆写。网络状态和有效配置变更均需连续两次观察一致。常规检查间隔一秒，系统调用与运行维护操作耗时另计。
- 文件检查覆盖路径被原子替换的保存方式。只在文件大小、修改时间或路径变化时重新解析 YAML；对照生成的运行缓存，防止订阅更新、应用内编辑和缓存写入造成重启循环。仅修改注释或格式不会重启。无效变更不覆盖运行缓存。
- 连接视图、托盘与历史统计通过同一 `MihomoClient` 快照缓存合并请求；关闭操作和内核代际变化会使快照失效。缓存失效期间返回的旧请求不会重新填入缓存。
- 流量、日志流退避从一秒开始递增并加入抖动，最高二十秒；有效数据帧、日志级别变化或内核代际变化重置退避。

没有新增依赖，也没有持久化格式迁移。多控制器、SSID 策略和完整菜单栏面板不属于本次实现。

## 自动测试

```sh
cargo fmt --all -- --check
cargo check --workspace --all-targets --all-features --locked
cargo test --workspace --all-features --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
ZENCLASH_MIHOMO_BINARY=/absolute/path/to/mihomo \
  cargo test -p zenclash-core --test real_automatic --locked -- --ignored --nocapture
```

`real_automatic` 使用独立临时目录、随机本地控制器端口和真实 Mihomo；不改变宿主机系统代理，不启用 TUN。覆盖：

1. 网络暂停后不触发崩溃恢复，联网恢复启动成功。
2. 恢复启动失败仍保留暂停状态，修复后可以再次恢复。
3. 手动停止后联网不启动，显式重启有效。
4. 退出标记阻止后续自动恢复。
5. 有效源配置变化更换进程且运行配置正确；内核拒绝的规则保持原进程与配置。

纯行为测试还覆盖协议筛选、真实时间排序、节点可用性与延迟排序、连接请求合并与关闭后失效、文件内容防抖和外部控制器排除。

## 手工验证步骤

以下步骤需要在 macOS、Windows、Linux 的实际桌面分别执行；自动测试不能代替原生接管与交互验证。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 连接筛选和身份 | 打开连接页，选择 TCP/UDP 和流量排序；展开某条连接，产生新连接并翻页 | 筛选排序后分页；展开状态属于同一连接，关闭动作命中该连接 |
| 时间排序 | 切换最新/最早连接顺序 | 按时间点排序，非法或缺失时间放在末尾 |
| 节点列表 | 测速后按延迟排序并隐藏不可用节点；翻页 | 有效延迟升序；未测速节点保留，失败节点隐藏；全部隐藏时有空状态说明 |
| 系统代理断网恢复 | 启动内核并启用系统代理，关闭所有上联接口，再恢复 | 暂停后释放本应用代理；恢复内核和此前代理意图；首页区分断网暂停与手动停止 |
| TUN 断网恢复 | 在已有授权下启用 TUN，断开并恢复上联接口 | 停止进程时释放 TUN；恢复后检查设备与路由证据，不仅检查配置开关 |
| 网络抖动 | 在一次观察间隔内断开并恢复接口 | 不因单次观察贸然停止；未知状态不当作断网 |
| 主动停止 | 在内核管理中停止，断开并恢复网络，随后点击重启 | 联网不会自行拉起；显式重启恢复运行与接管意图 |
| 外部编辑 | 编辑当前托管配置，连续保存或采用原子重命名保存 | 稳定有效变化触发重启；无效 YAML 或无效规则报错并保留当前运行状态 |
| 应用内更新 | 使用应用更新当前订阅或编辑配置 | 已应用内容不触发第二次自动重启 |
| 退出竞争 | 在恢复或配置重启期间退出应用 | 正常退出后没有遗留受管内核，系统代理不会被延迟恢复任务重新打开 |
| 重连 | 临时令控制器不可用，再恢复 | 流重连间隔递增且有上限；恢复有效帧后清除退避 |

观察网络状态使用本地接口地址及链路信息，不通过请求第三方网站判断在线。特殊虚拟网络、远程桌面和仅 VPN 上联环境需补充实机验证。
